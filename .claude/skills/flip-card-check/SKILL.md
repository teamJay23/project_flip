# flip-card-check — Flip 카드 채점

Flip의 핵심 약속은 "원문만 근거로 만든 카드"다. 이 스킬은 그 약속이 지켜지는지
PRD v1.4의 완료 조건으로 확인하고, 결과를 입문자도 읽을 수 있는 표로 남긴다.

## 언제, 무엇을 채점하나

| 상황 | 모드 |
|---|---|
| 사용자가 Flip 앱(또는 다른 AI)이 만든 카드를 붙여넣음 | **채점 모드** — 붙여넣은 카드를 채점 |
| 카드 없이 "테스트 돌려줘", "03번 확인해줘" | **생성+채점 모드** — 원문으로 카드를 직접 만들어 본 뒤 채점 |

테스트 번호를 말하지 않으면 어떤 테스트(01~04, 또는 전부)를 할지 한 번 묻는다.

## 테스트 파일

`docs/test-inputs/` 안의 파일마다 아래 구간이 있다.
- `## 원문 (이것만 복사)` 의 코드 상자 → 카드의 유일한 근거
- `## 모범 카드` → 비교 기준 (정답지가 아니라 "이 정도면 좋다"는 예시)
- `## 체크 포인트` → 함정 항목 포함. 함정은 그 원문에서 AI가 틀리기 쉬운 곳이다

## 카드 규칙 (PRD v1.4)

- 3-1: 카드 수 1장 이상 20장 이하
- 3-2: 앞면은 질문, 뒷면은 그 질문의 답
- 3-3: 각 면 3문장 이하
- 3-4: 각 면을 30초 안에 읽을 수 있음
- 3-5: 뒷면에 원문에서 찾을 수 없는 사실·숫자·이름·날짜가 0개. 표현이 달라도 뜻이 같으면 통과
- 4-a: 카드를 만들 수 없는 원문(예: 단어 1개)이면 카드 0장 → 실패 안내

## 생성+채점 모드 순서

1. **원문만 읽고 카드를 만든다.** 이때 모범 카드·체크 포인트는 아직 읽지 않는다.
   먼저 읽으면 정답을 보고 만든 셈이 되어, 실제 Flip의 AI가 어떻게 할지 알 수 없게 된다.
   - 원문에 있는 내용만 쓴다. 배경 지식, 예문, 다른 뜻, 유명한 수치를 덧붙이지 않는다.
   - 카드를 만들 근거가 부족하면(04처럼) 카드를 지어내지 말고 "카드 0장"으로 끝낸다.
   - 만든 카드를 먼저 표로 적어 둔 뒤 다음 단계로 간다.
2. 그다음 모범 카드와 체크 포인트를 읽고, 아래 "채점 방법"으로 채점한다.
3. 결과 맨 위에 "직접 만든 카드를 직접 채점한 것이라 후하게 나올 수 있음 — Flip 앱 결과로 다시 확인할 것"이라고 적는다.

## 채점 방법

- **3-1**: 카드 수를 센다.
- **3-2**: 앞면이 물음표 등 질문 형태인지, 뒷면이 그 질문에 대한 답인지 본다.
- **3-3**: 문장 수를 센다. 마침표·물음표·느낌표 또는 "~다."로 끝나는 단위를 한 문장으로 본다.
  마침표 없이 끝나는 짧은 구("마감 기한")는 1문장이다.
- **3-4**: 사람이 스톱워치로 재는 조건이라 확정하지 않는다. 한 면이 약 150자를 넘으면
  "30초 위험"으로 표시하고 나머지는 "사람 확인 필요"로 둔다.
- **3-5** (가장 중요): 뒷면마다 사실·숫자·이름·날짜·고유명사를 하나씩 뽑아,
  원문에서 같은 뜻의 문장을 찾아 인용한다. 찾지 못하면 위반이다.
  "아마 원문에 있었을 것" 같은 추측으로 통과시키지 않는다 — 근거 문장을 못 찾으면 위반으로 적는다.
  예문·추가 뜻처럼 사실·숫자·이름·날짜는 아니지만 원문에 없는 내용은 "팀 결정 필요"로 따로 적는다.
- **함정**: 체크 포인트의 함정 항목마다 걸렸는지 아닌지를 적는다.
- **모범 카드 비교**: 모범 카드가 다룬 핵심 중 빠진 것이 있으면 적는다. 빠진 것은 실패가 아니라 참고다.

## 결과 형식

아래 틀을 그대로 쓴다. 입문자가 읽으므로 쉬운 말로 쓴다.

```markdown
# 카드 채점 결과 — [테스트 번호·이름] ([채점 모드 / 생성+채점 모드])
- 날짜: YYYY-MM-DD
- 카드 출처: [Flip 앱 / 붙여넣은 결과 / 이 스킬이 직접 생성]

## 한눈에 보기
| 완료 조건 | 결과 | 한 줄 이유 |
|---|---|---|
| 3-1 카드 수 | ✅/❌ | |
| 3-2 질문/답 | ✅/❌ | |
| 3-3 3문장 이하 | ✅/❌ | |
| 3-4 30초 | 사람 확인 필요 / ⚠️ | |
| 3-5 원문에 없는 내용 0개 | ✅/❌ | |
| 함정 | 걸림 n개 / 0개 | |

## 카드별 확인
| # | 앞면 | 뒷면 | 문장 수(앞/뒤) | 3-5 근거 (원문 인용) |
|---|---|---|---|---|

## 3-5 위반 / 팀 결정 필요
- (없으면 "없음")

## 사람이 직접 확인할 것
- 각 면 스톱워치 30초 (3-4)
- (그 밖에 판단이 애매했던 것)

## 다음에 해볼 것
- (카드 생성 지시문을 고친다면 어디를 고칠지 한두 줄)
```

04 실패용처럼 카드가 0장이어야 하는 테스트는 카드별 확인 대신
"기대: 카드 0장 + 고정 안내 문구" 와 실제 결과를 비교하는 표를 쓴다.
고정 문구: "카드를 만들지 못했습니다. 원문을 확인한 후 다시 시도해주세요"

## 저장

결과를 `docs/test-results/YYYY-MM-DD-[테스트번호]-[모드].md` 로 저장하고 경로를 알려 준다.
같은 이름이 있으면 뒤에 `-2`, `-3`을 붙인다. 이 기록은 Phase 3에서 개선 근거로 쓰인다.
