## 남겨야 할 데이터
- 기준: PRD v1.4 정리본(`00_34. day14_prd_v1.4_final_structure.md`) 9절 "서비스가 기억하는 정보", 10절 역할(CODE → 프로그램 계산 / AI → AI 초안 / HUMAN → 사람 입력)
- 시트 한 줄 = 카드 1장 (같은 stack의 카드는 같은 stack ID를 가짐)
- 원문 텍스트, 카드(앞면 질문·뒷면 답·생성 순서), stack, 카드별 안다/모른다 기록, 복습 목록, 현재 라운드, 지금 보는 카드
- 보관 범위: 같은 탭 안(새로고침·다른 앱 다녀오기)에서만 유지, 탭을 닫으면 초기화 (PRD 9절)

## 열 정의
| 열 이름 | 예시 값 | 누가 정하나 (사람 입력 / 프로그램 계산 / AI 초안) | 비어 있어도 되나 |
|---|---|---|---|
| stack ID | S001 | 프로그램 계산 (카드 만들기에 성공할 때 붙임) | 아니요 |
| 카드 순서 | 1 | 프로그램 계산 (생성 순서, 1~20) | 아니요 |
| 원문 텍스트 | 광합성은 식물이 빛 에너지로 양분을 만드는 과정이다. … | 사람 입력 (붙여넣기) | 아니요 (띄어쓰기·줄바꿈만 있어도 빈 값) |
| 앞면 질문 | 광합성은 무엇인가? | AI 초안 (3문장 이하) | 아니요 |
| 뒷면 답 | 식물이 빛 에너지로 양분을 만드는 과정이다. | AI 초안 (3문장 이하, 원문에 있는 내용만) | 아니요 |
| 안다/모른다 기록 | 모른다 | 사람 입력 (안다 / 모른다) | 예 (아직 고르지 않은 카드) |
| 라운드 | 1 | 프로그램 계산 (마지막으로 고른 라운드) | 예 (아직 고르지 않은 카드) |
| 복습 목록 포함 | 예 | 프로그램 계산 (기록이 "모른다"면 예) | 아니요 (예 / 아니요) |
| 지금 보는 카드 | 아니요 | 프로그램 계산 (stack마다 "예"는 1장만) | 아니요 (예 / 아니요) |
| 상태 | 대기 | 사람 입력 (대기 / 승인 / 반려) | 아니요 |
| 확인자 | 홍길동(가상) | 사람 입력 | 승인 전에는 예 |
| 확인 시각 | 2026-10-20 20:30 | 프로그램 계산 | 승인 전에는 예 |

- 상태·확인자·확인 시각은 PRD 10절 "사람 CHECK"(3-2 질문/답, 3-4 30초, 3-5 원문에 없는 내용 0개)를 사람이 확인한 결과를 적는 칸입니다.
