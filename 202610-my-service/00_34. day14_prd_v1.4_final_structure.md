# Flip MVP PRD (양식 정리본)

Oct 2, 2026 · @Jay

PRD v1.4(2026-10-02, 강사님 피드백 반영본)의 내용을 13개 장 양식에 맞게 다시 배치한 문서다. 새 기능이나 새 결정은 넣지 않았고, 내용이 다르면 PRD v1.4를 따른다.

## 1. 서비스 한 줄 설명

나는 [자기계발 시간이 부족한 직장인]이 겪는 [자투리 시간(통근 중, 회사 휴게시간 등)을 자기개발에 쓰지 못하고 흘려보내는 문제]를 줄이기 위해, 첫 번째 해결 가설로 [학습하고 싶은 텍스트를 붙여넣으면 AI가 원문만 근거로 자투리 시간에 소비 가능한 학습 카드 묶음(최대 20장)을 만들고, 안다/모른다를 고르며 모르는 카드만 반복해 끝까지 학습하게 하는 서비스 흐름]을 시험한다.

## 2. 사용자와 문제

자기계발 시간이 부족한 직장인이 자투리 시간을 자기개발에 쓰지 못하고 흘려보낸다.

- **사용자**: 자기계발 시간이 부족한 직장인
- **상황**: 통근 중, 회사 휴게시간 등 자투리 시간. 저녁·주말에도 개인 시간이 거의 없음. 자투리 시간은 수면·모바일(게임/네이버 카페/유튜브)·수다·커피로 보냄
- **문제**: 자투리 시간을 자기개발에 쓰지 못하고 흘려보냄

### 근거

|   |   |
|---|---|
|근거|내용|
|본인 캘린더|첫 3개월은 계획을 세웠으나 실천하지 못했고, 이후로는 비어 있음|
|본인 이력서|입사 후 약 6개월간 방치, 7개월차에 1회 업데이트|
|본인 메모|자기개발 시도 언급 없음|
|「한국 성인의 평생학습실태」(2025, 국가승인통계)|참여 의사가 있었으나 못 한 취업자의 77.2%가 "직장 업무로 인한 시간 부족"을 이유로 꼽음|
|통계청 2024 통근 근로자 이동 특성|평균 출퇴근 73.9분, 수도권 82.0분|
|인크루트 설문(2023, 805명)|자기계발 시간대는 퇴근 후 60%, 주말 19.7%, 출근 전 아침 11.7%|

### 확인 필요

- 직장인들이 자투리 시간을 생산적으로 쓰고 싶어 하는지, 쉬고 싶어 하는지 (공개 자료 없음, 동기 설문 결과로 확인 예정)
- 자투리 시간을 이미 잘 쓰는 직장인과 전혀 못 쓰는 직장인을 나눠야 하는지
- 스마트폰 사용 비율(게임/네이버 카페/유튜브 약 4:4:2)은 추정치이며 기록으로 확인되지 않음
- 사용자가 다음 날에도 다시 와서 쓰는지 (이번 버전에는 저장이 없어 확인할 수 없음)

## 3. 이번 버전에서 해결할 범위

붙여넣기 → AI 카드 생성 → 안다/모른다 반복 → 완료까지, 한 번의 학습 흐름을 끝까지 쓸 수 있게 한다.

- 입력창에 텍스트 붙여넣기, 제출하기, 빈 입력이면 막고 안내하기
- 원문만 근거로 질문/답 카드 만들기 (최대 20장, 한 면 3문장)
- 20장 이하·한 면 3문장 이하인지 검사하기 (통과하지 못하면 생성 실패)
- 로딩 표시, 생성 실패 안내 (입력 화면 위에 고정 문구, [확인])
- 카드들을 stack 1개로 묶고 학습 상태 기억하기 (유지 범위는 9장)
- 첫 카드 앞면 보여주기, 카드를 탭해서 뒷면 보기
- "안다" 처리하기 ("← 알고 있음" 탭 / ← 스와이프)
- "모른다" 처리하기 ("모름 · 애매 →" 탭 / → 스와이프)
- 라운드가 끝나면 모른다 카드로 다음 라운드 시작하기
- 완료 화면 보여주기, [다시 학습] / [새로 만들기] 버튼

## 4. 이번 버전에서 하지 않을 것

학습 도중 빠져나가는 길은 탭을 닫는 것뿐이며, 이번 버전에서는 그대로 둔다.

### 써 보며 다시 검토할 것

- 진행도 표시 (기능 13) — 그래서 카드 수는 직접 넘기며 센다
- 라운드 변경 별도 표시 — 표시 없음으로 시작, 써 보며 필요성 확인
- AI가 실패 이유를 설명하는 안내 (짧은 원문 / 비윤리·개인정보 구분) — v1.4에서 CODE 고정 문구로 바꿈
- 이전 stack을 모아 두는 공간 (가칭: my library)

### 하지 않는 것

- 로그인(Kakao / Naver / Google), 이어하기(진행 위치·라운드 기억)
- 비로그인 데이터를 계정으로 옮기기, 비로그인 stack 3개 제한
- 50장 초과 시 A_1 / A_2 분할
- template 여러 버전 만들고 고르기 (수정 최대 4번, 원본 포함 5개)
- 개별 카드 스타일 변경, 질문/답 뒤집기, 앞뒤 구성 변경
- 학습 중 텍스트·카드 추가
- 카드 즐겨찾기(별)
- 완료 폴더, 학습 중 폴더, 폴더 간 이동
- 타인 stack ("준비 중" 안내 포함)
- 여러 stack을 오갈 때 진행 상태 유지
- 파일 업로드
- 외부 출처(대학·공공기관·권위자·주요 매체) 보강과 출처 표시
- [이전] / [다음(스킵)] 버튼

## 5. 핵심 사용자 행동 흐름

사용자는 8단계를 거쳐 한 stack을 끝까지 학습한다. 4~6단계는 모른다 카드가 없어질 때까지 반복된다.

1. 텍스트를 입력창에 붙여넣고 제출한다.
2. AI가 학습 카드를 생성한다.
3. 생성된 카드가 하나의 stack으로 묶여 탭을 닫기 전까지 유지된다.
4. 앞면(질문)을 확인하고, 카드를 탭해 뒷면(답)을 본다. (뒷면을 보는 것은 선택)
5. 안다(←) / 모른다(→)를 선택한다. (앞면에서도, 뒷면에서도 고를 수 있음)
6. 라운드가 끝나면 모른다 카드만 순서를 섞어 다시 학습한다.
7. 모든 카드를 알면 완료된다.
8. 완료 화면에서 [다시 학습] 또는 [새로 만들기]를 고른다.

## 6. 화면 요소와 기능 구조

화면은 4개(A 입력 · B 로딩 · C 학습 · D 완료)이고, 행동 흐름 4~6단계는 모두 C 학습 화면 하나에서 이어진다.

|   |   |   |
|---|---|---|
|화면|화면 요소|관련 기능|
|A. 입력 화면|입력창, [카드 만들기] 버튼, 빈 입력 안내 문구, 생성 실패 안내(고정 문구 + [확인], 이 화면 위에 띄움)|1, 2, 3, 7|
|B. 로딩 화면|로딩 표시 (사용자가 할 행동 없음). 화면 뒤에서 카드 생성과 검사가 진행됨|4, 5, 6|
|C. 학습 화면|카드(앞면 질문 / 뒷면 답), 카드 왼쪽 바깥 "← 알고 있음", 카드 오른쪽 바깥 "모름 · 애매 →"|9, 10, 11, 12, 14|
|D. 완료 화면|완료 메시지, [다시 학습], [새로 만들기]|15, 16, 17|

빈 입력이면 A에 그대로 머문다. 실패 안내는 A 위에 뜨고, [확인]을 누르면 원문이 남은 입력창으로 돌아간다.

기능 8(stack과 학습 상태 기억)은 특정 화면이 아니라 화면 B 이후 전체에 걸쳐 동작한다. 기능 13(진행도 표시)은 이번 버전에서 뺐다. 자세한 연결은 flip-flow-screen-feature-map.md (v1.3 기준).

## 7. 기능별 완료 조건

각 조건은 사람이 직접 해 보고 눈으로 확인할 수 있게 썼다. 조건 번호는 PRD v1.4 그대로다.

### 기능 1. 입력창에 텍스트 붙여넣기

- **1-1** 휴대폰에서 입력창을 길게 누르면 "붙여넣기"를 고를 수 있다.
- **1-2** 다른 앱에서 복사한 텍스트를 붙여넣으면, 입력창의 첫 문장과 마지막 문장이 원문의 첫 문장·마지막 문장과 같다.
- **1-3** 입력창 안을 스크롤하면 붙여넣은 텍스트를 끝까지 볼 수 있다.

### 기능 2. 제출하기

- **2-1** 입력창 아래에 [카드 만들기] 버튼이 보인다.
- **2-2** 텍스트가 들어 있는 상태에서 [카드 만들기]를 누르면 입력 화면이 사라지고 다음 화면으로 바뀐다.
- **2-3** [카드 만들기]를 빠르게 두 번 눌러도 카드 만들기는 한 번만 시작된다(두 번째 누름은 무시).

### 기능 3. 빈 입력이면 막고 안내하기

- **3-a** 띄어쓰기·줄바꿈만 넣고 [카드 만들기]를 누르면 입력 화면에 그대로 머문다.

### 기능 4. 원문만 근거로 질문/답 카드 만들기 (AI)

- **3-2** 모든 카드의 앞면은 질문이고, 뒷면은 그 질문에 대한 답이다.
- **3-4** 각 면을 눈으로 읽을 때 스톱워치로 30초를 넘지 않는다.
- **3-5** 원문과 대조했을 때, 뒷면에 원문에서 찾을 수 없는 사실·숫자·이름·날짜가 0개다. 표현이 달라도 뜻이 같으면 "원문과 맞음"으로 본다.
- **4-a** 아주 짧은 원문(예: 단어 1개)을 제출해서 카드가 만들어지지 않으면, 기능 7의 실패 안내가 보인다.

### 기능 5. 20장 이하·한 면 3문장 이하인지 검사하기

- **3-1** 1라운드를 끝까지 넘기며 센 카드 수가 1장 이상 20장 이하다.
- **3-3** 모든 카드의 각 면이 3문장 이하다(직접 센다).
- **5-a** 검사를 통과하지 못하면 카드가 보이지 않고, 기능 7의 실패 안내가 보인다.

### 기능 6. 로딩 표시

- **6-a** 로딩 중 다른 앱으로 갔다가 돌아오면, 그 사이 카드 만들기가 끝났을 경우 그 결과가 보인다.
- **6-b** [카드 만들기]를 누른 뒤 결과가 나올 때까지 로딩 화면이 보인다.

### 기능 7. 생성 실패 안내 (CODE)

- **7-a** 실패 안내에서 [확인]을 누르면 안내가 사라지고, 입력창에 직전에 제출한 원문이 그대로 들어 있다.
- **7-b** 세 가지 실패 경우(생성 실패 / 0장 / 검사 불통과) 모두 같은 안내 문구가 보인다.

### 기능 8. 카드들을 stack 1개로 묶고 학습 상태 기억하기

- **4-1** 카드 만들기가 끝나면 추가 조작 없이 첫 카드 앞면이 보인다.
- **4-2** 1라운드에서 같은 질문의 카드가 두 번 나오지 않는다.
- **4-3** 학습 중에 다른 앱으로 갔다가 돌아오거나 새로고침하면, 보던 카드와 같은 카드가 앞면으로 보이고 라운드와 안다/모른다 기록도 그대로다.
- **4-4** 탭을 닫거나 브라우저를 종료한 뒤 다시 열면 입력 화면부터 시작한다.

### 기능 9. 첫 카드 앞면 보여주기

- **5-1** 각 카드가 처음 나타날 때 앞면(질문)만 보이고 답은 보이지 않는다.
- **5-2** 판단 후 다음 카드로 넘어가면, 새 카드도 앞면부터 보인다.
- **5-3** 질문 글자가 카드 밖으로 넘치거나 잘리지 않고 끝까지 보인다.

### 기능 10. 카드를 탭해서 뒷면 보기

- **6-1** 앞면 상태에서 카드를 한 번 탭하면 뒷면(답)이 보인다.
- **6-2** 카드를 탭해도 다음 카드로 넘어가지 않는다(안다/모른다가 선택되지 않는다).
- **6-3** 답 글자가 카드 밖으로 넘치거나 잘리지 않고 끝까지 보인다.

### 기능 11. "안다" 처리하기

- 1차 (상태 변화, 탭)
    - **7-1** 앞면과 뒷면 모두에서 카드 왼쪽 바깥에 "← 알고 있음" 텍스트가 보인다.
    - **7-3** "← 알고 있음"을 탭하면 다음 카드 앞면이 보이고, 카드는 뒤집히지 않는다.
    - **7-4** 안다로 고른 카드의 질문을 메모해 두면, 다음 라운드에 그 질문이 나오지 않는다.
    - **7-5** 뒷면을 한 번도 보지 않은 앞면 상태에서도 7-3이 똑같이 동작한다.
- 2차 (제스처)
    - **7-2** 카드를 왼쪽으로 스와이프하면 7-3과 같은 결과가 나온다.

### 기능 12. "모른다" 처리하기

- 1차 (상태 변화, 탭)
    - **8-1** 앞면과 뒷면 모두에서 카드 오른쪽 바깥에 "모름 · 애매 →" 텍스트가 보인다.
    - **8-3** "모름 · 애매 →"를 탭하면 다음 카드 앞면이 보이고, 카드는 뒤집히지 않는다.
    - **8-4** 모른다로 고른 카드의 질문을 메모해 두면, 다음 라운드에 그 질문이 나온다.
    - **8-5** 뒷면을 한 번도 보지 않은 앞면 상태에서도 8-3이 똑같이 동작한다.
- 2차 (제스처)
    - **8-2** 카드를 오른쪽으로 스와이프하면 8-3과 같은 결과가 나온다.

### 기능 13. 진행도 표시 — 이번 버전에서 뺌

- 완료 조건 없음. 카드 수는 직접 넘기며 센다(3-1, 9-1).

### 기능 14. 라운드가 끝나면 모른다 카드로 다음 라운드 시작하기

- **9-1** 1라운드에서 모른다를 고른 수(예: 3장)와 다음 라운드에 나오는 카드 수가 같다.
- **9-2** 다음 라운드에 안다로 고른 카드가 1장도 나오지 않는다.
- **9-3** 1라운드의 카드 순서는 카드가 만들어진 순서와 같다. 2라운드부터는 라운드가 바뀔 때마다 순서를 무작위로 새로 정한다.
- **9-4** 다음 라운드에서 다시 모른다를 고른 카드는 그다음 라운드에 또 나온다.
- 참고: 무작위라서 우연히 이전과 같은 순서가 나올 수 있다.

### 기능 15. 완료 화면 보여주기

- **10-1** 1라운드에서 모든 카드를 안다로 고르면, 마지막 카드를 넘긴 직후 완료 화면이 보인다.
- **10-2** 여러 라운드를 거친 뒤 마지막 남은 카드를 안다로 고르면 완료 화면이 보인다.
- **10-3** 모른다 카드가 1장이라도 남아 있으면 완료 화면이 나오지 않고 다음 라운드가 시작된다.
- **10-4** 완료 화면에 완료를 알리는 메시지가 보인다.
- **10-5** 완료 화면에 [다시 학습]과 [새로 만들기] 버튼이 보인다.

### 기능 16. 다시 학습

- **16-a** [다시 학습]을 누르면 같은 stack의 카드 전체가 1라운드에 나온다(이전에 안다로 고른 카드 포함).
- **16-b** [다시 학습]의 1라운드 카드 순서는 처음 생성된 순서와 같다.

### 기능 17. 새로 만들기

- **17-a** [새로 만들기]를 누르면 입력 화면이 보이고, 입력창은 비어 있다.
- **17-b** [새로 만들기]로 새 카드를 만든 뒤에는 이전 stack의 카드가 나오지 않는다.

### 사람 CHECK

원문 3종(단어·문장 / 교재·기출 / 기사)으로 한 번씩, 만들어진 카드를 원문과 나란히 놓고 확인한다.

- 앞면이 질문이고 뒷면이 그 질문의 답인가 (3-2)
- 각 면이 30초 안에 읽히는가 (3-4)
- 뒷면에 원문에 없는 사실·숫자·이름·날짜가 없는가. 표현이 달라도 뜻이 같으면 맞음으로 봄 (3-5)

### 비교할 기준·원본

- 원본: 사용자가 붙여넣은 원문 텍스트
- 기준: 카드 최대 20장, 한 면 3문장 이하, 한 면 30초 이내

### 실패했을 때 대응

- 카드 만들기 실패 / 0장 / 검사 불통과: 입력 화면 위에 고정 안내 → [확인] → 원문이 남은 입력 화면 (기능 7)
- 카드 내용이 원문과 다를 때: 만들면서 정한다 (12장)
