## 시작 입력 (6-2)
- 내 PRD 파일(없으면 공통 확장 과제 번호):00_34. day14_prd_v1.4_final_structure.md
- 오늘 만들 첫 기능 한 줄:입력 화면(기능1,2,3)
- 완료 확인표 3줄 이상(입력 → 화면에 있어야 할 결과, 실패 줄 1개 이상):
  1. 다른 앱에서 복사한 긴 텍스트를 입력창에 길게 눌러 붙여넣기 → "붙여넣기"가 나오고, 입력창의 첫 문장·마지막 문장이 원문과 같고, 입력창 안을 스크롤하면 끝까지 보인다 (1-1, 1-2, 1-3)
  2. 텍스트가 들어 있는 상태에서 [카드 만들기] 누르기 → 입력창 아래에 버튼이 보이고, 누르면 입력 화면이 사라지고 다음 화면(임시 "카드 만드는 중…")으로 바뀐다 (2-1, 2-2)
  3. 텍스트를 넣고 [카드 만들기]를 빠르게 두 번 누르기 → 다음 화면으로 한 번만 넘어간다(두 번째 누름은 무시) (2-3)
  4. (실패) 띄어쓰기·줄바꿈만 넣고 [카드 만들기] 누르기 → 입력 화면에 그대로 머물고 빈 입력 안내 문구가 보인다 (3-a)
  5. (실패) 아무것도 넣지 않고 [카드 만들기] 누르기 → 4번과 같이 입력 화면에 머물고 안내 문구가 보인다 (3-a)
