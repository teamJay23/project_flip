## 3. Tinder식 방향 — 팀 질문 (결정 필요)

| | 오른쪽(→) | 왼쪽(←) | 근거 |
|---|---|---|---|
| Tinder 관례 | **좋아요 (긍정)** | 넘김 (부정) | tinder.com/about-tinder 글: "Swipe Right™", "It's good you didn't accidentally swipe left" (2026-10-31 열어 봄) |
| Flippy (06번) | 안다 | 아직 배우는 중 | 06 문서 1절 |
| **Flip PRD** | **모른다** ("모름 · 애매 →") | **안다** ("← 알고 있음") | PRD 기능 11·12, CLAUDE.md |

- **충돌:** admin이 떠올린 Tinder와 Flip PRD의 방향이 **반대**다. Tinder에 익숙한 사용자는 "알아요"를 오른쪽으로 밀 가능성이 높다.
- **지금(3·4단계)은 탭 버튼**이라 바로 문제가 되지는 않는다. 하지만 버튼 글자에 화살표(←, →)가 있고, 19번 문서의 버튼 위치(왼쪽 끝 / 오른쪽 끝)도 이 방향을 따른다 → **4단계 시작 전에 정하는 것이 좋다.**

**팀 질문 (새 번호는 07 문서에 넣을 때 정함)**: 안다/모른다 방향을 어떻게 할까?
| 선택지 | 장점 | 단점 |
|---|---|---|
| (가) PRD 그대로 (안다 ←, 모른다 →) | 문서·코드 수정 없음 | Tinder·Flippy와 반대 → 2차 스와이프 때 잘못 미는 일이 생길 수 있음 |
| (나) Tinder식으로 바꿈 (안다 →, 모른다 ←) | 사용자 습관과 같다. admin이 생각한 그림과 같다 | PRD 기능 11·12, CLAUDE.md, 06·19 문서 수정. **PRD 변경이라 팀·강사님과 정해야 함** |
- 마케터 의견: 사용자 습관을 생각하면 **(나)를 추천**한다. 다만 PRD를 바꾸는 일이라 **결정은 팀·강사님**이 한다.

## 4. 추천 — 3·4단계에 쓸 사이트

1. **AWWWARDS (1순위)** — 로그인 없이 검색이 되고, 태그로 "Mobile"을 고를 수 있고, flashcard·quiz·swipe 사례가 실제로 나왔다.
2. **웹어워드 (2순위, 문구용)** — 화면 디자인보다 **국내 학습 서비스의 한국어 안내 말투**를 볼 때. 3·4단계 버튼 문구는 PRD에 정해져 있으니, 주로 A·B 화면 문구 다듬을 때 쓴다.
- 디비컷은 이번 단계에 맞지 않는다. 비핸스·핀터레스트는 admin이 직접 브라우저로 열어 보고 판단한다 (내가 확인하지 못함).

### admin용 15분 사용법 (AWWWARDS 기준)
| 시간 | 할 일 |
|---|---|
| 0~2분 | **찾을 것 1개만** 정한다. 예: "카드 뒤집기 움직임" 또는 "카드 아래 버튼 2개 배치" |
| 2~7분 | 휴대폰 브라우저로 awwwards.com → 검색창에 `flashcard` / `quiz` / `swipe` 중 하나 → 결과 중 태그에 **Mobile**이 있는 것 3개만 연다 |
| 7~11분 | 각 사이트에서 **가져올 것 1줄**만 적는다: 배치 / 움직임 / 느낌 중 하나. 색은 적지 않는다 (우리 색은 `:root` 변수로 정해져 있음) |
| 11~13분 | 범위 밖인지 확인: 진행도(몇 장 남음), [다음]·[이전] 버튼, 점수·통계, 새 색 → 있으면 "참고 제외" |
| 13~15분 | 화면 캡처 1~2장 + 주소를 팀장에게 보낸다. 팀장이 19번 문서와 맞는지 보고 반영할지 정한다 |

## 5. 이번에 배운 것
- 레퍼런스 사이트도 **성격이 다르다**: 디비컷·웹어워드는 "회사 홈페이지", Awwwards는 "인터랙션", 비핸스·핀터레스트는 "이미지". 우리처럼 **움직임이 핵심인 카드 화면**은 인터랙션 쪽이 맞다.
- "Tinder처럼"이라는 말에는 **방향 관례**가 함께 따라온다. 그림만 빌려 오면 PRD와 부딪히는 부분을 놓칠 수 있다.
