## 3. 고지 4겹 — MVP와 Phase 3에 무엇이 필요한가

> 고지 4겹 = ① 첫 화면 문구 ② 이용약관 ③ 개인정보처리방침 ④ 선택 동의 (Lilys 벤치마킹, 10번 문서)

### 3-1. 한눈에 보기

| 겹 | MVP (2026-12-12 평가, 사용자 = 팀·강사님·평가자) | Phase 3 (W09~, 실제 직장인 사용자) |
|---|---|---|
| ① 첫 화면 문구 | **필요 — 이미 있음.** 더할 것: "만 18세 이상" 한 줄 (약관 나이 조건). 원문을 시트에 저장하기로 하면 "Flip도 기록을 저장" 추가 | 필요. MVP 문구 + [자세히] (02 계획 3-4번 ④) + "AI 카드는 틀릴 수 있어요" (10번 가져올 점 1) |
| ② 이용약관 | **로그인 없으면 선택.** 한 쪽짜리 "이용 안내"(나이, 넣지 말 것, AI 결과가 틀릴 수 있음, 무료 시험 서비스라 멈출 수 있음)를 추천 | **추천.** 위 내용 + 약관 바꿀 때 알리는 방법. 법적 필요 여부는 **확인 필요** |
| ③ 개인정보처리방침 | **로그인을 MVP에 넣으면 필요할 가능성 높음** (이메일 저장 + Google 인증 요구). 로그인이 없고 원문도 저장하지 않으면 필요성 낮음 — 단 **확인 필요** | **필요하다고 보고 준비** (로그인·이메일 저장, 100명 넘으면 Google 인증). PIPC 작성지침(2026.4.)을 따름. Google(미국)로 가는 정보를 어떻게 적을지(국외 이전인지, 처리 위탁인지) **확인 필요** |
| ④ 선택 동의 | **필요 없음** (선택으로 더 모으는 정보가 없으면). 단, 원문·카드를 "서비스 개선"용으로 저장하기로 하면 선택 동의로 받는 것을 추천 | 원문·카드 저장, 나이·지역 같은 추가 정보(08 계획 5번)를 받으면 **필수와 따로** 선택 동의 (Lilys 방식) |

### 3-2. MVP를 두 경우로 나누면

| 경우 | 필요한 것 (추천) | 만드는 데 드는 것 |
|---|---|---|
| **MVP-가: 로그인 없이 평가** (7·8단계를 평가 뒤로) | ① 첫 화면 문구 + 18세 한 줄. 시트에는 익명 기록만, 원문은 저장 안 함(08 질문 2의 (가)) | 문구 한 줄 추가 (코드 아주 조금) |
| **MVP-나: 로그인까지 평가** | 위 + ③ 개인정보처리방침 페이지 + 로그인 화면(E)에 처리방침 링크 + 이메일 수집 안내 문구. Google OAuth는 **테스트 상태(100명 이하)** 로 시험 | 처리방침 글 1편(PIPC 지침 참고) + 공개 페이지 1개 + 법적 확인 |

- **→ 결정 e로 MVP-나(로그인 포함)가 정해졌다.** 아래는 결정 전 원래 추천(기록용): **추천: MVP-가.** CLAUDE.md "지금 단계"가 "한 줄 흐름이 끝까지 작동하는 것"이 우선이고, PRD 9번에서도 로그인은 "10번 결정 후"다. 평가 전에 처리방침·법적 확인까지 하면 일정이 빠듯하다. 단 **로그인을 MVP에 넣을지는 팀·강사님이 정할 일**이다.

### 3-3. 처리방침·약관 페이지를 어디에 둘까 (Phase 3 또는 MVP-나)

| 방법 | 비용 | 설정 난이도 | 장점 | 단점 |
|---|---|---|---|---|
| Notion 공개 페이지 | 개인 무료 플랜 있음 (팀 요금은 확인 필요) | 쉬움 | 강사님이 말한 "Notion 가이드"와 한곳에 모을 수 있다 | 주소가 notion 주소라 Google 인증에서 "우리 도메인"으로 인정되는지 **확인 필요** |
| Vercel에 페이지 1개 추가 (예: `privacy.html`) | 무료 (이미 Vercel 사용) | 보통 (파일 하나, 배포) | 앱과 같은 주소라 Google 인증 요구(홈페이지·처리방침 같은 곳)에 맞추기 쉬울 것 같다(확인 필요) | 프로젝트 규칙 "앱 화면은 단일 HTML"과 부딪히는지 팀 확인 (앱 화면이 아니라 안내 페이지) |
| Slashpage (Lilys 사용) | 확인 필요 | 쉬움 | 한국어 약관 페이지 사례가 있음 | 새 도구를 배워야 함 |

- **추천: Vercel 페이지 1개** — Google 로그인 인증과 같은 주소에 두기 쉽다. 단 단일 HTML 규칙과 함께 **팀 확인 필요**.
- **→ 결정 g**: 화면 하단 링크로 연결한다. 위치·페이지는 7단계 계획 때 이 표를 보고 정한다.

## 7. 이번에 배운 것
- 국가법령정보센터는 조사 도구로 조문이 읽히지 않을 때가 있다. 조항 번호를 쓸 때는 원문을 연 뒤에만 "확인됨"으로 적는다.
