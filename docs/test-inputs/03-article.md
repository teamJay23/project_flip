# 03. 기사 — 망각곡선과 간격 반복 (약 750자)

- 목적: 긴 설명 글에서 카드 분량(한 면 3문장, 30초)을 지키는지, AI가 "아는 척" 숫자를 덧붙이지 않는지 확인
- 확인할 완료 조건: 3-1, 3-3(한 면 3문장 이하), 3-4(30초 이내), **3-5(원문에 없는 사실·숫자 0개)**
- 원문 출처: Flip 테스트용으로 직접 작성한 기사 형식의 글 (저작권 걱정 없음)

## 원문 (이것만 복사)

```
잊어버리는 것에도 패턴이 있다 — 망각곡선과 간격 반복

열심히 외운 단어가 며칠 뒤 기억나지 않는 경험은 누구에게나 있다. 독일의 심리학자 헤르만 에빙하우스는 1885년 출간한 책에서, 기억이 시간에 따라 어떻게 사라지는지 연구한 결과를 발표했다. 그는 의미 없는 음절을 스스로 외운 뒤, 시간이 지나 다시 외우는 데 드는 노력을 측정했다.

그 결과 기억은 학습 직후에 가장 빠르게 줄어들고, 시간이 지날수록 줄어드는 속도가 느려지는 것으로 나타났다. 이 변화를 그래프로 그린 것이 '망각곡선'이다.

에빙하우스는 같은 내용을 한 번에 몰아서 반복하는 것보다, 간격을 두고 나누어 반복할 때 더 오래 기억된다는 점도 관찰했다. 이를 '간격 효과'라고 부르며, 이 원리를 학습에 적용한 방법을 '간격 반복'이라고 한다.

오늘날 많은 플래시카드 앱이 간격 반복을 쓴다. 잘 아는 카드는 더 긴 간격을 두고 보여 주고, 잘 모르는 카드는 더 자주 보여 주는 방식이다. 짧은 시간이라도 자주 복습하는 것이 한 번에 오래 공부하는 것보다 기억에 유리할 수 있다는 뜻이다.

다만 효과는 학습 내용과 사람에 따라 다를 수 있다. 중요한 것은 잊어버리는 것을 실패로 보지 않고, 다시 꺼내 보는 과정 자체를 학습으로 받아들이는 태도다.
```

## 모범 카드 (AI 결과와 비교할 기준)

|#|앞면 (질문)|뒷면 (답)|
|---|---|---|
|1|기억이 시간에 따라 사라지는 과정을 연구한 독일 심리학자는?|헤르만 에빙하우스. 1885년 출간한 책에서 연구 결과를 발표했다.|
|2|에빙하우스는 기억을 어떻게 측정했나?|의미 없는 음절을 스스로 외운 뒤, 시간이 지나 다시 외우는 데 드는 노력을 측정했다.|
|3|망각곡선에서 기억은 언제 가장 빠르게 줄어드나?|학습 직후. 시간이 지날수록 줄어드는 속도는 느려진다.|
|4|'간격 효과'란?|한 번에 몰아서 반복하는 것보다 간격을 두고 나누어 반복할 때 더 오래 기억되는 현상.|
|5|플래시카드 앱은 간격 반복을 어떻게 적용하나?|잘 아는 카드는 더 긴 간격을 두고, 잘 모르는 카드는 더 자주 보여 준다.|

## 체크 포인트

- [ ] 카드 수가 1~20장 사이인가? (5~8장 안팎이 자연스러움)
- [ ] 각 면이 3문장 이하이고, 스톱워치로 30초 안에 읽히는가?
- [ ] **함정 ①**: "20분 후 42%를 잊는다", "하루 뒤 67%" 같은 구체적인 수치가 나오면 → 원문에 없음 → 3-5 실패 (인터넷에 자주 돌아다니는 숫자라 AI가 덧붙이기 쉬움)
- [ ] **함정 ②**: 책 제목, 다른 학자 이름, 특정 앱 이름(Anki 등)이 나오면 → 원문에 없음 → 3-5 실패
- [ ] 숫자는 "1885년" 하나뿐 — 다른 연도·숫자가 있으면 원문과 대조하기
