# 04. 실패용 — 너무 짧은 원문

- 목적: 카드를 만들 수 없는 원문일 때 실패 안내가 제대로 뜨는지 확인
- 확인할 완료 조건: 4-a(카드가 안 만들어지면 실패 안내), 7-a(원문이 입력창에 남아 있음), 7-b(같은 고정 문구)

## 원문 (이것만 복사)

```
사과
```

## 기대 결과 (카드가 아니라 화면 동작)

1. [카드 만들기]를 누르면 로딩 화면이 보인다.
2. 카드가 보이지 않고, 입력 화면 위에 아래 문구와 [확인]이 뜬다.
   > 카드를 만들지 못했습니다. 원문을 확인한 후 다시 시도해주세요
3. [확인]을 누르면 안내가 사라지고, 입력창에 "사과"가 그대로 남아 있다.

## 체크 포인트

- [ ] 실패 안내 문구가 위 문구와 글자 하나까지 같은가?
- [ ] [확인] 뒤 입력창에 "사과"가 남아 있는가?
- [ ] **함정**: AI가 "사과는 어떤 과일인가? → 빨간 과일"처럼 카드를 만들어 버리면 → 원문에 없는 내용으로 카드를 지어낸 것 → 3-5 실패이자 4-a 실패. 이 경우 결과를 그대로 기록해 두기 (프롬프트를 고칠 근거가 됨)

## 참고: 함께 해 볼 빈 입력 테스트 (기능 3)
카드 생성 테스트는 아니지만, 같은 단계에서 확인하면 편해요.

- [ ] 입력창에 띄어쓰기·줄바꿈만 넣고 [카드 만들기] → 입력 화면에 그대로 머무는지 (3-a)
