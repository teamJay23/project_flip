# 05. 실패용 — 의미 없는 글 (F-1, 40자)

- 목적: 길이 규칙은 넉넉히 통과하지만 학습할 내용이 없는 글일 때, AI가 카드를 지어내지 않고 0장을 주는지 확인
- 확인할 완료 조건: 4-a(카드가 안 만들어지면 실패 안내), 7-a(원문이 입력창에 남아 있음), 7-b(같은 고정 문구)
- 04 "사과"(2자)는 v1.5 길이 규칙에서 먼저 막혀서 4-a 확인에 쓸 수 없다. 그래서 이 원문을 따로 만들었다 (`drafts/01` 4번 F-1)
- 길이: 띄어쓰기 빼고 40자, 한글이 주인 글 (자음만 있는 글자도 한글로 셈). 10자 경계와 떨어뜨리려고 40자 안팎으로 만들었다

## 원문 (이것만 복사)

```
ㅋㅋㅋㅋㅋ ㅎㅎㅎㅎㅎ ㅁㄴㅇㄹ ㅁㄴㅇㄹ 가나다라 마바사 아자차카 타파하 ㅋㅋㅋㅋ ㅎㅎㅎㅎ
```

## 기대 결과 (카드가 아니라 화면 동작)

1. [카드 만들기]를 누르면 로딩 화면이 보인다. (입력 화면에서 막히지 않는다)
2. 카드가 보이지 않고, 입력 화면 위에 아래 문구와 [확인]이 뜬다.
   > 카드를 만들지 못했습니다. 원문을 확인한 후 다시 시도해주세요
3. [확인]을 누르면 안내가 사라지고, 입력창에 원문이 그대로 남아 있다.

## 체크 포인트

- [ ] 로딩 화면까지 갔는가? (입력 화면에서 "조금 더 긴 글을…"이 뜨면 길이 규칙 문제)
- [ ] 실패 안내 문구가 위 문구와 글자 하나까지 같은가?
- [ ] [확인] 뒤 입력창에 원문이 남아 있는가?
- [ ] **함정 1**: "가나다라 마바사…" 때문에 "한글 자음의 순서는?" 같은 카드를 만들면 → 원문에 없는 지식으로 지어낸 것 → 3-5 실패이자 4-a 실패
- [ ] **함정 2**: "ㅋㅋ의 뜻은? → 웃음" 같은 카드도 원문에 없는 내용이다 → 실패
- 실패하면 결과를 그대로 기록해 두기 (프롬프트를 고칠 근거가 됨)
