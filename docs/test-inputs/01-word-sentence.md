# 01. 단어·문장 — 영어 단어 10개

- 목적: 가장 단순한 원문으로 카드 형식이 맞게 나오는지 확인
- 확인할 완료 조건: 3-1(1~20장), 3-2(앞면=질문 / 뒷면=답), 3-3(한 면 3문장 이하), 3-5(원문에 없는 내용 0개)
- 사용법: 아래 "원문" 상자 안의 내용만 복사해서 Flip 입력창에 붙여넣기

## 원문 (이것만 복사)

```
abandon - 버리다, 포기하다
acquire - 얻다, 습득하다
brief - 짧은, 간단한
commute - 통근하다; 통근
deadline - 마감 기한
efficient - 효율적인
frequent - 잦은, 빈번한
improve - 개선하다, 향상시키다
review - 복습하다, 검토하다
schedule - 일정; 일정을 잡다
```

## 모범 카드 (AI 결과와 비교할 기준)

|#|앞면 (질문)|뒷면 (답)|
|---|---|---|
|1|abandon의 뜻은?|버리다, 포기하다|
|2|acquire의 뜻은?|얻다, 습득하다|
|3|commute의 뜻은?|통근하다; 통근|
|4|deadline의 뜻은?|마감 기한|
|5|review의 뜻은?|복습하다, 검토하다|

## 체크 포인트

- [ ] 카드 수가 1~20장 사이인가? (10장 안팎이 자연스러움)
- [ ] 모든 앞면이 질문 형태인가?
- [ ] 뒷면 뜻이 원문과 같은가? (표현이 조금 달라도 뜻이 같으면 통과)
- [ ] 원문에 없는 예문·발음기호·다른 뜻이 추가되지 않았나?
    - 예문이 붙어 나오면 3-5 위반으로 볼지 팀이 정하기 (사실·숫자·이름·날짜는 아니지만 "원문에 없는 내용"임)
- 참고: "버리다, 포기하다를 뜻하는 단어는?"처럼 거꾸로 묻는 카드도 질문/답 형식이면 통과
